# Microjuego_Asteroids_1.0

Microjuego desarrollado en Unity como práctica de la asignatura de Fundamentos de Videojuegos. Se trata de un shooter 2D de desplazamiento horizontal inspirado en Asteroids, en el que el jugador debe destruir meteoritos y conseguir la máxima puntuación posible.

## Demo

La versión ejecutable se encuentra en la carpeta **Build**.

Para jugar, ejecutar:

`Build/Practica1_Nave.exe`

## Mecánicas

- Movimiento en cuatro direcciones (WASD o flechas).
- Disparo continuo manteniendo pulsada la barra espaciadora.
- Spawn automático de meteoritos desde la derecha.
- Meteoritos grandes que se fragmentan en dos pequeños.
- Sistema de puntuación.
- Game Over.
- Pausa (ESC).
- Reinicio de la partida (R).

## Controles

 Tecla     Acción 

 W / ↑     Mover arriba
 S / ↓     Mover abajo
 A / ←     Mover izquierda
 D / →     Mover derecha
 Espacio   Disparar
 ESC       Pausar / Reanudar
 R         Reiniciar
